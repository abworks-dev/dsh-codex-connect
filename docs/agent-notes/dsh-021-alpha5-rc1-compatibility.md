# DSH alpha.5 / rc.1 compatibility and plugin Alpha 5

Canary issues [#343](https://github.com/franksong2702/dsh-codex-connect/issues/343) and [#344](https://github.com/franksong2702/dsh-codex-connect/issues/344), from run `39014191845` against source `edf0bb77359feb2e87708fedcde808559034e777`, fail during isolated installation because exact DSH `0.2.1-alpha.5` and `0.2.1-rc.1` are absent from the plugin requirements. Both stock hosts passed a declaration-only installation/runtime experiment. That explains the observed admission failure; it does not prove that all unrelated upstream interfaces are unchanged.

Codex Connect `0.2.0-alpha.5` adds only these two hosts to the 19 exact peer declarations, packaged compatibility metadata, development gate and shared Host/browser diagnostic policy. It retains all eight existing hosts and the runtime-identity diagnostics merged in [#345](https://github.com/franksong2702/dsh-codex-connect/pull/345). No provider/client API adaptation is added. The development SDK remains `0.1.7-rc.1`, plugin-owned pi-ai remains `0.85.1`, and the Node requirement and feature defaults remain unchanged. Mixed sets and later versions remain unverified; missing required metadata remains unknown.

The release candidate requires the complete check, browser regressions and a ten-host isolated matrix using identical package bytes. Verification covers model preparation, disposal, retained recovery and synthetic image paths without reading real accounts or sending live provider requests. These checks do not replace OAuth, real model/image requests, authenticated new-host browser or full user acceptance.

Candidate installation records in `verified-compatibility.json` describe checked exact combinations, not npm availability. Public installation recommendations remain on the confirmed `0.2.0-alpha.4` package until Alpha 5 publication and independent readback. The alpha channel may advance through the protected release workflow; latest promotion, service upgrades/restarts and closing #339 are outside this release.
