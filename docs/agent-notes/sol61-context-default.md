# Sol61 product-default alignment — 2026-10-19

Refs #338. This source follow-up aligns the base `gpt-6.1-sol` context budget with the **500,000-token** default described by the [official Work/Codex article](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex). It is not a new published package or a measured account/endpoint capacity.

The older [immutable Codex static catalog](https://github.com/openai/codex/blob/d63a9b8344cfe58bc78bbe319b560378fc8756ef/codex-rs/models-manager/models.json#L177-L349) still contains default 272,000, `max_context_window` 872,000 and `auto_compact_token_limit: null`. The installed official CLI `0.162.0-alpha.17.2` contains the same catalog (472,072 bytes with its source newline; SHA-256 `943ca7fe1d19ed019054158303f0dbbd80b3bef43b3aa425a71aa7cb3fb52c2b`). This does not make that snapshot current account-scoped metadata or turn a null compaction field into a numeric trigger.

The plugin's pinned pi-ai `0.85.1` catalog currently lacks Sol61. Its missing entry now gets a dedicated 500,000 fallback. Both the production adapter and diagnostic catalog explicitly mark their bundled-static factory boundary: if a known bundled Sol61 entry has the old 272,000 default, only that context field is calibrated. Different bundled values are preserved. Generic/provider-sourced metadata wins, even if its explicit value is 272,000; it must not be marked bundled-static when supplied by an authenticated remote catalog. No new remote/account discovery is added.

Precedence is explicit user `contextWindowOverrides`, then authoritative provider metadata, then this versioned calibration of known bundled static data/missing fallback. A null/reset restores the effective base default. Other model defaults, Sol61's 872,000 local override ceiling, output limits and finite SSE transport remain unchanged. The Host compression algorithm/threshold settings are unchanged; a larger advertised context budget can naturally alter Host-calculated absolute budgets. No API 1M/1.05M limit, price, account entitlement or power to accept 500k on every route is inferred.

Regressions cover the production catalog and real Host adapter, missing and stale bundled entries, source precedence (including explicit provider 272k), differing newer bundled values, other-model preservation, actual Cordis settings override/null reset, and prepared stream snapshots with unchanged output/transport. The baseline had four failing default-calibration cases and four passing provider/override controls. Tests use synthetic credentials/provider streams and no real provider requests. The [October 16 note](gpt61-capability-calibration.md) remains the historical Alpha 5 evidence checkpoint.
