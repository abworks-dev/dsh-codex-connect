# 0.2.0-alpha.10

Prepared for the existing Alpha-only release workflow. A candidate record does not establish npm publication; public installation recommendations stay on the previously confirmed Alpha 9 pairing until npm/tag/release readback.

- Adds only exact DSH `0.2.1-rc.3`, retaining the eleven previous hosts, consistent-package checks and plugin-owned pi-ai `0.85.1`. The candidate is based on actual npm artifacts; rc.3's Git source tag remains unverified. See the [compatibility evidence](../agent-notes/dsh-021-rc3-compatibility.md).
- Includes the merged default-off, read-only `codex_connect_quota` tool. Startup `enableQuotaTool: true` enables a minimal quota projection with observation time and unknown/stale states. It exposes no account identifiers, balances, credentials or raw responses, and adds no model/account switching or scheduling. The optional [quota-awareness skill](../skills/codex-quota-awareness/SKILL.md) is not installed automatically.
- Includes the compact Standard/Fast/Ultrafast menu for Codex Astra and Sol61. The complete EN/ZH disclosure uses intrinsic height at enlarged text sizes while preserving the separate information action and account gating. Speed choice is a request preference; entitlement and served tier remain unverified.

Existing defaults, permissions, cancellation and Task pause remain. Keyless installed-Host and Chromium checks are separate from real OAuth/model, native Desktop/iPhone and full-user acceptance. This release preparation does not upgrade a Host, change a daily installation, restart a service or promote `latest`.
