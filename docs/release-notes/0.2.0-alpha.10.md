# 0.2.0-alpha.10

Published on 2026-10-23 through the existing Alpha-only workflow, with protected recovery completing the missing GitHub records after npm processing outlasted bounded readback. [Publication evidence](../../INSTALL.md#020-alpha10-verified-publication) preserves the original failed run, exact release SHA and matching archive hashes. npm `alpha` is Alpha 10; `latest` remains Alpha 1. The immutable package retains its pre-publication recommendation; the repository commands below use the confirmed published pair.

- Adds only exact DSH `0.2.1-rc.3`, retaining the eleven previous hosts, consistent-package checks and plugin-owned pi-ai `0.85.1`. The compatibility work is based on actual npm artifacts; rc.3's Git source tag remains unverified. See the [compatibility evidence](../agent-notes/dsh-021-rc3-compatibility.md).
- Includes the merged default-off, read-only `codex_connect_quota` tool. Startup `enableQuotaTool: true` enables a minimal quota projection with observation time and unknown/stale states. It exposes no account identifiers, balances, credentials or raw responses, and adds no model/account switching or scheduling. The optional [quota-awareness skill](../skills/codex-quota-awareness/SKILL.md) is not installed automatically.
- Includes the compact Standard/Fast/Ultrafast menu for Codex Astra and Sol61. The complete EN/ZH disclosure uses intrinsic height at enlarged text sizes while preserving the separate information action and account gating. Speed choice is a request preference; entitlement and served tier remain unverified.

Existing defaults, permissions, cancellation and Task pause remain. Keyless installed-Host and Chromium checks are separate from real OAuth/model, native Desktop/iPhone and full-user acceptance. Publication does not upgrade a Host, change a daily installation, restart a service or promote `latest`.

For an explicitly requested installation on a declared exact Host, preserve the intended existing profile:

```sh
dsh plugin --profile web add dsh-codex-connect@0.2.0-alpha.10
```

Replace `web` with that profile name. Requesting a plugin installation does not authorize a Host upgrade or daily-service restart.
