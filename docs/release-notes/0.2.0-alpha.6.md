# Codex Connect 0.2.0-alpha.6

Alpha maintenance release. Publication is performed only by the protected main OIDC workflow; this source document is not publication evidence. npm `alpha` is the intended channel; `latest` is not promoted.

## Changes since published Alpha 5

- **DSH 0.2.1-rc.2 compatibility and Search ownership — #352.** Admit only the exact rc.2 package set alongside the previous ten Hosts. Adapt to the Host-owned Volatile search choice using its owner-fiber change event. Later Host choices retain priority through A → B → A and unset → B → unset, including updates entirely between searches. Preserve source limits, fetch routing and teardown. Mixed or missing Host packages and unlisted versions stay unverified.
- **Bounded bili preflight activity — #349.** Opt-in `preflightActivity` with `protocol: bili-v1` handles valid preflight SSE activity within explicit startup, activity and total limits; comments do not extend an unlimited request or replace caller cancellation. Its endpoint/configuration policy, finite ordinary idle behavior and timeout ownership remain bounded. It is disabled by default. Synthetic tests do not close the real bili/Windows acceptance work in #340.
- **Retained Task lifecycle and effort regressions — #350.** Preserve the useful remaining lifecycle/effort and installed-Host regression coverage after the runtime fix in #331. This adds validation and documentation; Task remains publicly paused and no experiment is reopened.
- **Reproducible build-tool artifacts — #353.** Update tsdown to 0.23.1 and its locked build dependencies, including Rolldown1.2.14's CommonJS top-level-this wrapper fix, and synchronize emitted chunks/imports. The declaration generator/native parser dependency changes remain a disclosed development-toolchain risk. No comprehensive supply-chain audit or physical Windows compiler validation is claimed; the existing Node24 source-build minimum24.11 remains unchanged.
- **Published Alpha 5 installation guidance — #348.** Retain the corrected historical publication/recovery evidence. Published older npm archives are immutable.

The unmerged credential-storage/migration work in #327 and other open dependency PRs are excluded. Default models, permissions, optional-feature defaults, public Task pause and Node runtime requirements are unchanged. No daily profile, Host upgrade or service restart is part of publication.

## Validation and installation scope

The candidate must pass a frozen install, complete check, Chromium, pack inventory/dry-run and same-artifact isolated installation/runtime checks for all eleven exact Hosts before release. Final exact commit, CI and artifact identities are recorded with publication evidence. These synthetic checks cover Search round trips, default preservation, model registration/preparation, resource disposal and retained recovery contracts; they do not establish real-account entitlement or Desktop/Windows physical-device acceptance.

After this exact version is published and independently read back, use the existing intended profile:

```sh
dsh plugin --profile web add dsh-codex-connect@0.2.0-alpha.6
```

Use a consistent declared Host package set and plugin-owned pi-ai0.85.1. The public installation recommendation remains on the already published version during preparation and is updated separately after publication. Do not bypass Host gates or operate on a running daily Desktop profile.
